C++ 迴圈控制結構

學習如何使用迴圈，讓程式重複執行指定的指令。

1. 什麼是迴圈？

在程式設計中，迴圈（Loop）是一種控制結構， 可以讓程式在符合特定條件時，重複執行某段程式碼。

假設今天需要輸出 1 到 100 的數字， 如果沒有使用迴圈，就必須撰寫大量重複的輸出指令。 使用迴圈則可以大幅減少程式碼，提升程式的可讀性。

核心觀念： 迴圈主要由初始化、條件判斷、執行內容與更新變數組成。

2. for 迴圈

for 迴圈適合用在已經知道大約需要重複執行幾次的情況。 它將初始化、條件判斷與變數更新集中在同一行。

基本語法

for (初始化; 條件判斷; 更新變數) {
    // 重複執行的程式碼
}

範例：輸出 1 到 5

#include <iostream>
using namespace std;

int main() {

    for (int i = 1; i <= 5; i++) {
        cout << i << endl;
    }

    return 0;
}

執行結果

1
2
3
4
5

執行流程如下：

  1. 設定變數 i = 1。
  2. 判斷 i 是否小於或等於 5。
  3. 如果條件成立，輸出 i。
  4. 執行 i++，讓 i 增加 1。
  5. 回到條件判斷，直到條件不成立。

3. while 迴圈

while 迴圈會先判斷條件是否成立， 只有條件為 true 時才會執行迴圈內的程式碼。

基本語法

while (條件判斷) {
    // 重複執行的程式碼
}

範例：輸出 1 到 5

#include <iostream>
using namespace std;

int main() {

    int i = 1;

    while (i <= 5) {
        cout << i << endl;
        i++;
    }

    return 0;
}

執行結果

1
2
3
4
5
注意： 如果忘記更新變數 i，可能導致條件一直成立， 造成無窮迴圈（Infinite Loop）。

4. do-while 迴圈

do-while 迴圈與 while 迴圈最大的差異在於， 它會先執行一次程式碼，再判斷條件是否成立。

基本語法

do {
    // 至少執行一次的程式碼
} while (條件判斷);

範例：輸出 1 到 5

#include <iostream>
using namespace std;

int main() {

    int i = 1;

    do {
        cout << i << endl;
        i++;
    } while (i <= 5);

    return 0;
}

執行結果

1
2
3
4
5
重要觀念： do-while 至少會執行一次，即使一開始的條件不成立也一樣。

5. 三種迴圈的比較

三種迴圈的主要差異如下：

  • for： 適合已知執行次數的情況。
  • while： 適合依據條件決定是否繼續執行的情況。
  • do-while： 適合至少需要執行一次的情況。

其中，for 與 while 都是先判斷條件再執行， 而 do-while 則是先執行再判斷。

6. break 與 continue

break

break 可以直接結束目前所在的迴圈， 即使條件仍然成立，也不會繼續執行。 

for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        break;
    }

    cout << i << endl;
}

執行結果：

1
2

continue

continue 會跳過本次迴圈剩餘的程式碼， 直接進入下一次迴圈。 

for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    cout << i << endl;
}

執行結果：

1
2
4
5

7. 重點整理

  • for 迴圈：適合已知重複次數。
  • while 迴圈：先判斷條件，再決定是否執行。
  • do-while 迴圈：至少執行一次。
  • break：直接跳出目前迴圈。
  • continue：跳過本次迴圈，繼續下一次。
  • 注意更新控制變數，避免產生無窮迴圈。
學習建議： 建議實際修改迴圈的起始值、結束條件與更新方式， 觀察輸出結果的變化，會更容易理解迴圈的執行流程。
